# TokenIsland v0.3.2

灵动岛展开界面新增独立“退出”按钮，关闭应用更加直接。

## 更新

- 展开界面右下角加入带电源图标的“退出”按钮，点击即可关闭 TokenIsland。
- 未登录、连接中或连接异常时也可以使用退出按钮。
- 保留原有菜单退出入口、新版应用图标、用量监控与开机自启开关。

## 下载与安装

下载 `TokenIsland-0.3.2-macos-arm64.dmg`，打开后将 `TokenIsland.app` 拖入 `Applications`。更新前先退出旧版应用，再替换并重新启动。

- 系统要求：macOS 14 或以上。
- 处理器：Apple Silicon（arm64），当前附件不适用于 Intel Mac。
- 依赖：安装带内置 Codex CLI 的新版 ChatGPT Mac 应用。
- 附件包含对应的 `.dmg.sha256` 校验文件。

## 构建与数据说明

当前应用采用 ad-hoc 开发签名，尚未进行 Developer ID 签名和 Apple 公证，macOS 可能提示无法验证开发者。

账号日统计可能延迟，账号接口目前不提供精确小时明细；可以切换到本机实时小时曲线。普通 ChatGPT 聊天的完整 Token 用量暂不支持。

本版本执行自动化测试、展开界面演示预览、DMG 镜像校验，以及挂载后的应用签名、版本、架构和图标检查。
