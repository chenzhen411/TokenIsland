# TokenIsland v0.3.1

为 TokenIsland 加入全新 macOS 应用图标：深石墨底、薄荷绿玻璃胶囊，以柱形和圆点呼应 Token 用量与剩余额度。

## 更新

- 应用包内置完整 ICNS，包含 16 至 1024 像素的普通及 Retina 图标。
- 图标已接入 macOS 应用配置与构建流程，DMG 和 ZIP 中的应用均包含新图标。
- 保留 v0.3.0 的用量监控、点击展开与收起、统计范围切换及开机自启开关。

## 下载与安装

下载 `TokenIsland-0.3.1-macos-arm64.dmg`，打开后将 `TokenIsland.app` 拖入 `Applications`。更新前先退出旧版应用，再替换并重新启动。

- 系统要求：macOS 14 或以上。
- 处理器：Apple Silicon（arm64），当前附件不适用于 Intel Mac。
- 依赖：安装带内置 Codex CLI 的新版 ChatGPT Mac 应用。
- 附件包含对应的 `.dmg.sha256` 校验文件。

## 构建与数据说明

当前应用采用 ad-hoc 开发签名，尚未进行 Developer ID 签名和 Apple 公证，macOS 可能提示无法验证开发者。

账号日统计可能延迟，账号接口目前不提供精确小时明细；可以切换到本机实时小时曲线。普通 ChatGPT 聊天的完整 Token 用量暂不支持。

本版本执行自动化测试、DMG 镜像校验，以及挂载后的应用签名、版本、架构和多尺寸图标检查。
