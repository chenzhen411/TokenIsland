# TokenIsland v0.3.0

原生 macOS 灵动岛样式用量监控，面向 ChatGPT Work / Codex 任务。

## 功能

- 顶部紧凑显示今日 Token 用量与订阅窗口剩余额度。
- 点击展开、再次点击收起，支持外部交互收起；长数值保持单行。
- 查看小时曲线和最近 30 天账号用量热力日历。
- 切换“当前账号”与“本机实时”统计范围，明确显示数据来源与同步状态。
- 未授权时引导 ChatGPT 官方登录。
- 提供开机自启开关，可在菜单栏或灵动岛“更多”菜单中开启或关闭。

## 下载与安装

下载 `TokenIsland-0.3.0-macos-arm64.dmg`，打开后将 `TokenIsland.app` 拖入 `Applications`，然后从“应用程序”启动。

- 系统要求：macOS 14 或以上。
- 处理器：Apple Silicon（arm64）。当前附件不适用于 Intel Mac。
- 依赖：安装带内置 Codex CLI 的新版 ChatGPT Mac 应用。
- 附件包含对应的 `.dmg.sha256` 校验文件。

## 构建与数据说明

当前应用采用 ad-hoc 开发签名，尚未进行 Developer ID 签名和 Apple 公证，macOS 可能提示无法验证开发者。

账号日统计来自服务端汇总，可能延迟；账号接口目前不提供精确小时明细。小时图可展示本机任务事件，或在账号今日数据可用时展示日累计值的观测增量。普通 ChatGPT 聊天的完整 Token 用量暂不支持。

本版本已通过 24 项自动化测试，开机自启的实际开启与关闭已验证。DMG 创建后执行镜像与内含应用签名校验。
